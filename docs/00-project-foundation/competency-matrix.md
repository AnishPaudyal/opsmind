# Job-Skill Gap and Competency Matrix

Last updated: 2026-07-30

## Purpose

This matrix connects project work to demonstrable job skills. It prevents the
roadmap from becoming a list of technologies without evidence.

## Evidence Levels

| Level | Meaning |
| --- | --- |
| Foundation | Can explain the concept and reproduce a guided example |
| Applied | Can implement it in OpsMind and validate the result |
| Operational | Can deploy, observe, troubleshoot, secure, and document it |
| Portfolio | Can defend tradeoffs and show durable evidence to another person |

## Skills the Project Can Only Partially Address

OpsMind can demonstrate practical judgment and implementation, but it cannot by
itself replace:

- Experience operating a large production organization.
- Work with real enterprise scale, politics, and compliance obligations.
- Team leadership and cross-functional delivery history.
- Employer-specific domain knowledge.

These limitations should be stated honestly in portfolio and interview use.

## Evidence Rule

A competency is not considered demonstrated because a dependency appears in a
manifest. Evidence must include implementation, validation, documentation, and
an explanation of tradeoffs at the appropriate level.
